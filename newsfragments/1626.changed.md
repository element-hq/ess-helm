Run the MatrixRTC Authorisation Service as an application service so that it can authenticate to Synapse on behalf of users, e.g. to manage their MSC4140 delayed leave events.

When Synapse is deployed by the chart, the registration is generated by `initSecrets` and loaded by Synapse, which also gets the `msc4502_enabled` and `msc4512_enabled` experimental features. If `initSecrets` is disabled, `matrixRTC.appserviceRegistration` must now be provided.

When Synapse is not deployed by the chart, the service only runs as an application service if `matrixRTC.appserviceRegistration` is provided. The same registration must then be loaded by your homeserver.
